# tribooms_librarian

_Educational script written for a Father & Son Coding Education Stream at [Tribooms Coding Twitch Stream](https://www.twitch.tv/tribooms)_

# Purpose

Backups are a great thing.  However, manual backups onto an external hard drive over the years has left me with 10 folders in root from 10 sources.  This is a script to check for duplicate files in all subfolders of a root directory.
